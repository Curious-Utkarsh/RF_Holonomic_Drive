# RF-Controlled Holonomic (Mecanum) Drive

[![Arduino](https://img.shields.io/badge/MCU-Arduino-00979D?logo=arduino)](https://www.arduino.cc/)

A four-wheel mecanum robot driven over a 433 MHz RF link: one Arduino reads the operator's controls and transmits commands with VirtualWire, the second decodes them and drives the four wheels for forward, sideways and diagonal motion.
